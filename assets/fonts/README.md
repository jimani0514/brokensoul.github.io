# Website fonts

Self-hosted original WOFF2 files, licensed under SIL OFL 1.1. Include this whole directory when deploying. Individual licenses and exact source URLs / SHA-256 hashes are retained. Font binaries have not been edited. Upstream unicode-range subsets download only as the visible text requires. No runtime requests to Google Fonts or third-party font CDNs.

Pretendard Variable: Korean, body/UI, Latin and Cyrillic fallback. Space Grotesk: Latin display and studio identity. Noto Sans JP / SC: Japanese and Simplified Chinese.
